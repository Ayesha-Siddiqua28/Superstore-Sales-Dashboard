# Superstore Sales Dashboard

## Overview

This project was completed as part of the iNeuBytes Data Analytics Internship.

The dashboard was created in Tableau using the Sample Superstore dataset to analyze sales performance and provide interactive business insights.

## Features

- Sales by Category
- Monthly Sales Trend
- Profit by Region
- Sales by Segment
- Category Sales Share
- Top 10 Products by Sales
- Interactive Filters (Region, Category, Segment)

## Tools Used

- Tableau Public
- Sample Superstore Dataset
- GitHub
- Google Docs
