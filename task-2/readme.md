# Task 2 - Power BI Dashboard

## 📌 Project Title
Sales Data Analysis and Interactive Dashboard using Power BI

## 📖 Description
This project focuses on analyzing sales data using Microsoft Power BI. An interactive dashboard was created to visualize key business metrics and generate meaningful insights from the dataset. The dashboard enables users to understand sales performance, customer behavior, and product trends through various charts and KPIs.

## 🎯 Objectives
- Analyze the given sales dataset.
- Create an interactive Power BI dashboard.
- Visualize important business metrics.
- Generate insights to support data-driven decision-making.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Microsoft Excel / CSV Dataset

## 📊 Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Total Orders
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Top Performing Products
- Interactive Filters and Slicers

## 📁 Files Included
- `Task2.pbix` – Power BI project file
- `dataset.csv` – Dataset used for analysis
- `report.pdf` – Dashboard report (if included)
- `screenshots/` – Dashboard screenshots
- `README.md` – Project documentation

## 📈 Key Insights
- Identified top-performing product categories.
- Compared regional sales performance.
- Analyzed monthly sales trends.
- Evaluated overall business performance using KPIs.
- Presented data through interactive visualizations.

## ▶️ How to Open
1. Download the repository.
2. Open the `Task2.pbix` file using Microsoft Power BI Desktop.
3. Explore the dashboard using the available filters and visualizations.

## 📷 Output
The dashboard provides:
- Interactive visualizations
